# ARF 生态系统架构总览 V1.1



**文档目的:** 本文档是ARF项目的最高级别架构纲领，旨在为所有团队成员提供一个关于系统全部模块的、统一的、全面的信息索引。



## 第一部分：生态系统全景



ARF是一个覆盖机器人智能**全生命周期**的、**云-边协同**的生态系统，由两大核心平面构成。

- **ARF云端平面 (Cloud Plane):** 智能的“**摇篮**”和“**健身房**”。负责数据处理、模型训练、仿真评测和大规模管理任务。
- **ARF边缘平面 (Edge Plane):** 智能的“**身体**”和“**执行者**”。负责在机器人本体上实时运行感知、决策和控制任务。

## 第三部分：标准作业流程 (SOP) 概览 V1.1



| **SOP ID** | **面向角色**   | **核心目标**                                                 | **主要活动 (细化流程)**                                      | **关键交付物**                                               |
| ---------- | -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **SOP-01** | **科研人员**   | 探索并验证新的具身智能算法。                                 | 1. **【发现数据】** 使用`Data Hub`的**语义搜索**快速找到相关数据集。 2. **【启动环境】** 使用`arf-cli dev cloud-start`一键拉取预配置的云开发环境。 3. **【研发训练】** 在云端环境中进行模型设计与训练。 4. **【初步验证】** 将模型连接到`仿真模块`实例，进行功能验证。 | 1. 模型文件与`infer.py`脚本 2. 算法说明与性能报告            |
| **SOP-02** | **核心开发者** | 将科研算法工程化，并安全、可靠地集成到ARF生态中。            | 1. **【定义契约】** 与科研人员共同定义算法的`.proto`接口。 2. **【封装打包】** 将算法封装成标准的ACR容器。 3. **【全面评测】** 将容器提交到`评测模块`，执行标准化的**Sim-to-Real差距分析**和**安全性验证**。 4. **【发布上线】** 评测通过后，将容器发布到`插件市场`。 | 1. 版本化的ACR容器镜像 2. 包含Sim-to-Real差距的详细评测报告  |
| **SOP-03** | **产业用户**   | 在生产环境中高效、稳定地部署和使用ARF解决方案。              | 1. **【按需选配】** 从`应用层`的**技能商店**中选择并安装符合业务需求的技能包。 2. **【自动校准】** 部署团队使用`HAL`的**在线自校准**功能，快速完成现场硬件的标定。 3. **【灰度上线】** 使用`舰队管理`的**A/B测试**功能，将新应用灰度部署到部分机器人进行验证。 4. **【智能运维】** 通过统一控制台监控机器人状态，并接收`HAL`的**预测性维护**告警。 | 1. 一套稳定运行的、个性化的机器人生产系统 2. 数据驱动的运维决策报告 |
| **SOP-04** | **二次开发者** | 基于ARF平台，为最终客户高效地开发和交付定制化的机器人应用。  | 1. **【高效调试】** 使用`Dev`模块的**可视化套件**和**“时间旅行”调试器**，快速定位和解决问题。 2. **【组合创新】** 从`插件市场`调用官方或社区的算法与驱动，作为应用基础。 3. **【开发新能】** 使用Python SDK编写自定义的`DIL`决策逻辑或新的`ACR`容器。 4. **【分发获益】** 将解决方案打包成新的“技能”，并通过`插件市场`分发给自己的客户。 | 1. 一个或多个定制化的“技能”插件 2. 发布到`插件市场`并可能产生收益的新插件 |
| **SOP-05** | **家庭用户**   | 安全、便捷地使用家庭服务机器人，并通过日常交互为生态贡献有价值的数据。 | 1. **【开箱即用】** 通过移动App引导机器人完成联网与自检。 2. **【下载新能】** 在`应用层`的“**技能商店**”中浏览并一键安装新功能（如“智能陪聊”、“健康提醒”）。 3. **【个性互动】** 机器人通过`应用层`的**个性化引擎**，逐渐学习用户的偏好和习惯。 4. **【隐私共建】** (在用户授权下) 加入“机器人进化计划”，通过`训练模块`的**联邦学习**机制，在不上传隐私数据的前提下，帮助机器人变得更聪明。 | 1. 一个能不断学习和成长的个性化机器人助手 2. 持续更新的技能库 |
